# 02 创建一个游戏的开始界面

在我们设计与开发游戏的过程中，开始界面是玩家进入游戏的第一印象，对于我们开发者来说，我们也更希望有个快速启动项目的入口。
反正我是面对着一大堆的资源和代码，感觉有个开始界面会更好开始下面的开发。开始界面可以后期再进行美术设计和功能完善。

## 第一步：创建一个新的关卡

UE5 的设计是基于关卡的，我们的游戏世界就是由一个个关卡组成的，所以我们首先需要创建一个新的空关卡来作为我们的开始界面。

在 Content/myGame 目录下，右键点击选择 "New Folder"，命名为 "Maps"。然后进入 Maps 文件夹，右键点击选择 "New Level"，命名为 "L_StartMenu"。

:::details UE5 的命名规范

在 UE5 中，为了直观的识别资源的类型，我们通常会在资源名称前加上一个前缀。

例如，关卡我们使用 "L_"，蓝图类使用 "BP_"，材质使用 "M_" ,"WBP_" 代表 Widget Blueprint 等等。

这种命名规范可以帮助我们更快地找到和管理资源。

同样的，在编写代码时，我们也会使用类似的命名规范来区分不同类型的变量和函数。

常见的类类型根据 UE5 的设计，分为以下几类：

- Actor：游戏世界中的对象，例如角色、道具、环境等，通常以 "A" 开头，例如 "APlayerCharacter"。
- Component：Actor 的组成部分，例如碰撞组件、渲染组件等，通常以 "C" 开头，例如 "CHealthComponent"。
- Widget：用户界面元素，例如按钮、文本框等，通常以 "W"开头，例如 "WMainMenu"。

对于普通的类，我也建议使用项目名称作为前缀，例如 "MyGame" 项目的类可以命名为 "MyGamePlayerController"或"MGCharacter",这样可以避免与其他项目的类名冲突。

:::

## 第二步：设置开始界面为默认关卡

创建好关卡后，我们需要将它设置为游戏的默认关卡，这样当我们运行游戏时，就会直接进入这个开始界面。
在 UE5 的编辑器中，点击菜单栏的 "编辑"，选择 "项目设置"。在左侧的设置列表中，找到 "地图和模式" 选项。在 "默认地图" 部分，将 "编辑器启动地图" 和 "游戏默认地图" 都设置为我们刚才创建的 "L_StartMenu"。
